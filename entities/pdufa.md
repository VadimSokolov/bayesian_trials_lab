## What it is
PDUFA, the Prescription Drug User Fee Act, is the law, periodically reauthorized, under which sponsors pay fees and FDA commits to review goals and meeting timelines. [3/formal-meetings-under-pdufa] The current commitments are in the PDUFA VII goals letter for fiscal years 2023 through 2027. [3/formal-meetings-under-pdufa] The guidance *Formal Meetings Between the FDA and Sponsors or Applicants of PDUFA Products* (August 2026) withdraws the December 2017 guidance. [3/formal-meetings-under-pdufa]

## Why it matters
It defines six meeting types: Type A, Type B, Type B (EOP), Type C, Type D and INTERACT. [3/formal-meetings-under-pdufa] Type C is the usual route for design questions between milestones, such as a Bayesian analysis plan. [3/formal-meetings-under-pdufa]

## In the book
- FDA responds to a request within 14 calendar days for Type A, Type B (EOP) and Type D, and within 21 for Type B and Type C. [3/formal-meetings-under-pdufa]
- The meeting is scheduled within 30 days for Type A, 60 for Type B, 70 for Type B (EOP), 75 for Type C and 50 for Type D. [3/formal-meetings-under-pdufa]
- A Type C meeting on a novel design takes roughly three months from request to answer. [3/formal-meetings-under-pdufa]

## Pitfalls
Minutes are not a binding contract, but an agreement documented in minutes is persuasive. [3/formal-meetings-under-pdufa]

## Check yourself
- Q: Which meeting suits a stalled program? A: Type A. [3/formal-meetings-under-pdufa]
- Q: How soon is a Type C meeting scheduled? A: Within 75 days of receipt. [3/formal-meetings-under-pdufa]
