## What it is
BOIN is an R package for the design and simulation of Bayesian optimal interval phase I dose-finding trials. [sec-software-tools]

## Why it matters
The book marks it as relevant to the dose-finding chapter. [sec-software-tools]

## In the book
The build machine had BOIN 2.7.2. [sec-software-tools] The book lists BOIN among the R packages on CRAN and marks it as relevant to the dose-finding chapter, Chapter 17. [sec-software-tools] Its listed alternative, bcrm, was archived on CRAN on 8 May 2026. [sec-software-tools] The book says the build machine's other tools were not checked, so no version is given for bcrm. [sec-software-tools]

## Pitfalls
The descriptions in the book cover only the purpose of each tool, so a reader should consult the documentation for current features and versions. [sec-software-tools]
