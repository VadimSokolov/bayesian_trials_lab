## What it is
ICH M11, the Clinical Electronic Structured Harmonised Protocol (CeSHarP), reached Step 4 in November 2025. [23/structured-protocols-ich-m11-and-spirit-2025]
It comes with a harmonized template and a technical specification, so protocols present the same information in the same place and can be exchanged in a format acceptable to regulators. [23/structured-protocols-ich-m11-and-spirit-2025]

## Why it matters
Neither M11 nor SPIRIT 2025 is specific to Bayesian designs, so the practical consequence is a mapping problem. [23/structured-protocols-ich-m11-and-spirit-2025]
The structured format is harmonized across regulators, which helps. [23/ema-and-other-regulators]

## In the book
M11 has sections where design and statistics go, and a Bayesian design has components the template does not name: the prior, simulation-based calibration and predictive probability rules. [23/structured-protocols-ich-m11-and-spirit-2025]
The book places the prior with the statistical hypotheses and analysis methods, the decision rules with the interim analysis section, the operating characteristics with the sample size justification, and the detailed model and computation in the SAP. [23/structured-protocols-ich-m11-and-spirit-2025]
The sponsor checklist asks that the protocol be mapped into the M11 template and SPIRIT items with the Bayesian components where a reviewer would look. [23/checklists]

## Pitfalls
The test of a good mapping is that a reviewer who has read only the protocol knows the design is Bayesian, what the success criterion is and where the simulation report is. [23/structured-protocols-ich-m11-and-spirit-2025]
A protocol that mentions Bayesian methods only in an appendix invites the first review question to be where the prior is. [23/structured-protocols-ich-m11-and-spirit-2025]

## Check yourself
- Q: Where does the book put the operating characteristics in an M11 protocol? A: With the sample size justification. [23/structured-protocols-ich-m11-and-spirit-2025]
- Q: Does M11 name the prior? A: No, the template does not name Bayesian components. [23/structured-protocols-ich-m11-and-spirit-2025]
