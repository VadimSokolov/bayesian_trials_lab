## What it is
trialr is an R package for Bayesian clinical trial designs fitted with Stan. [sec-software-tools] It includes dose-finding and phase II designs. [sec-software-tools]

## Why it matters
It is one of the established tools listed for readers who want existing implementations. [sec-software-tools]

## In the book
The book lists it among the R packages on CRAN, and did not check its version. [sec-software-tools]

## Pitfalls
The descriptions in the book cover only the purpose of each tool, so a reader should consult the documentation for current features and versions. [sec-software-tools]

## Check yourself
- Q: Which engine does trialr use to fit designs? A: Stan. [sec-software-tools]
- Q: Which kinds of designs does it include? A: Dose-finding and phase II designs. [sec-software-tools]
